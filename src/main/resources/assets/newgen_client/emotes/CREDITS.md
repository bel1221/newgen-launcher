# Emote credits

The emotes are Emotecraft emote files, downloaded free from the Emotecraft website and bundled with the author's
credit kept. Each emote's author is also shown in the game, in Mods > Emotes > Edit wheel.

Animations are played with Player Animation Library (MIT, by Zigy and dima_dencep), nested in this mod's jar.
No Emotecraft code is included. Files are imported with tools/EmoteImport.java.
